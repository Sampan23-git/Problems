# Rhythm game

## Як запустити

Браузери блокують fetch() локальних JSON-файлів, якщо просто відкрити .html подвійним кліком
(протокол file://). Тому проєкт треба запускати через локальний сервер:

**Windows:** подвійний клік на `start.bat` → у браузері відкрити http://localhost:8000/
**macOS / Linux:** у терміналі `./start.sh` → у браузері відкрити http://localhost:8000/

Потрібен встановлений Python 3 (`python --version` / `python3 --version`, щоб перевірити).
Немає Python — підійде будь-який інший локальний сервер, наприклад `npx serve` (потрібен Node.js)
або розширення "Live Server" у VS Code.

Вікно термінала/cmd із сервером має лишатися відкритим, поки граєте.

## Як влаштована гра

Час нот береться напряму з аналізу треку (`beat_times`, `onset_times`, `intensity_curve`
у файлах `Біти/*.json`), а не з випадкового таймера — тому стрілки прилітають на кнопку
точно в момент відповідного біту/ноти в аудіо, синхронізовано з `audio.currentTime`.

Складність (швидкість падіння та частота нот) підлаштовується під `intensity_curve` треку:
у тихіших місцях нот менше і летять вони повільніше, у гучних/насичених місцях — більше нот
і швидший політ. Логіка — у `beatmapEngine.js` (побудова чарту й розрахунок швидкості) та
`game-runtime.js` (сам ігровий цикл, влучання, рахунок).
